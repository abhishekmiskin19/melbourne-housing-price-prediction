# Melbourne Housing Price Prediction Using Machine Learning

## Project Overview

This project focuses on predicting housing prices using Machine Learning techniques on the Melbourne Housing Dataset. The project includes data cleaning, preprocessing, exploratory data analysis (EDA), feature engineering, label encoding, model building, and evaluation using Random Forest Classifier.

The goal of this project is to analyze housing market trends and build a predictive model that can estimate property prices based on different property features.

---

# Dataset Information

The dataset contains information related to properties such as:

- Suburb
- Address
- Number of Rooms
- Property Type
- Price
- Seller Information
- Distance from City
- Bathroom Count
- Car Parking
- Land Size
- Building Area
- Year Built
- Region Name
- Property Count
- Latitude & Longitude

# Project Workflow

## 1. Data Exploration
- Loaded the dataset
- Checked unique values
- Identified missing values

## 2. Data Preprocessing
- Filled categorical missing values with 'Other'
- Filled numerical missing values using mean
- Dropped remaining null values
- Applied Label Encoding on categorical columns

## 3. Data Visualization
- Created bar plots for data analysis
- Explored relationships between features

## 4. Model Building
- Feature and target selection
- Train-test split
- Applied Random Forest Classifier

## 5. Model Evaluation
Evaluated model using:
- Accuracy Score
- Precision Score
- Recall Score
- Classification Report
- Confusion Matrix
